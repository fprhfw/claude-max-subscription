## 订阅前要准备什么？

WildAI 的 Claude 流程要求用户先登录自己的 Claude 账号，再获取 Cookie。Cookie 本质上是浏览器保存的登录凭证之一，不是普通的邀请码或订单号。提交前应认真核对页面和账号，避免误传。

建议准备以下内容：

- 一个可以正常登录 Claude 的账号。
- Chrome 浏览器。
- Cookie-Editor 浏览器扩展。
- 稳定的网络环境。
- 付款所需的微信或支付宝。
- 能接收订单通知的邮箱。

WildAI 的帮助文档说明，Cookie 需要从已经登录 Claude 的页面导出，格式通常是 JSON，并且要完整复制。只复制一部分，或者从错误页面导出，可能导致验证失败。

### Cookie 怎么导出？

大致步骤如下：

1. 在 Chrome 中登录自己的 Claude 账号。
2. 打开 Cookie-Editor 扩展。
3. 选择导出功能，并导出为 JSON。
4. 回到 WildAI 订阅页面。
5. 将完整 Cookie 粘贴到对应输入框。
6. 等待平台验证账号状态。

不要把 Cookie 发给无关人员，也不要在多个平台重复提交。提交完成后，如果浏览器或 Claude 账号仍处于登录状态，建议及时检查账号的活动会话和安全设置。

## 哪些情况可能导致开通失败？

Claude 订阅并不是提交 Cookie 后百分之百自动成功。WildAI 的帮助文档列出了几类常见问题，其中一些与账号当前状态有关。

### 账号已有逾期账单

如果 Claude 账号处于 Overdue 状态，或者之前的订阅扣款失败，Cookie 验证可能无法通过。通常需要先进入 Claude 账号的 Billing 页面处理逾期账单，让账号恢复到 Free 状态，再重新提交订阅。

### 账号仍有有效订阅

如果账号当前已经有有效的 Pro 或 Max 订阅，重新提交订阅可能遇到验证失败。续费前应先确认当前套餐、到期时间和账单状态，不要在不清楚的情况下重复开通。

### 触发身份验证

Claude 可能要求部分账号完成身份验证。WildAI 的帮助文档明确说明，平台不能保证绕过 Claude 官方的 KYC 检查。如果账号被要求提交身份资料，第三方平台也不一定能够继续完成订阅。

### 网络环境频繁变化

WildAI 的教程提醒，Claude 对代理、VPN 和 IP 变化比较敏感。频繁切换网络节点，可能增加账号验证失败或触发风控的概率。开通和后续使用时，尽量保持相对稳定的网络环境。

这不是“换一个节点就一定能解决”的问题。Claude 官方仍然拥有最终的账号审核和服务控制权，任何第三方都不能保证账号永远不会触发验证或限制。
